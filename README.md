# TerraPulse — ground truth for a moving planet

**Station-verified, uncertainty-quantified land-motion intelligence from NASA–ISRO NISAR.**
Built for the NASA International Space Apps Challenge.

Website: https://terrapulse-eta.vercel.app/ 

TerraPulse turns radar epochs into decision-ready ground-motion reports for the people
responsible for roads, water and safety — city engineers, hazard agencies, water managers —
and it refuses to show a number without its error bar and its evidence.

| | |
|---|---|
| **What** | Deformation atlas + AOI motion reports with GNSS validation and provenance receipts |
| **Missions** | NISAR L2 GCOV (provisional, released 2026-07-20) + Sentinel-1 (via NASA ASF) baseline |
| **Truth** | Nevada Geodetic Lab GNSS station velocities — every report is validated against them |
| **Honesty** | Conformal (Jackknife+/split) intervals with published coverage; receipts with SHA-256 hashes |
| **Status** | End-to-end working product: pipeline → API → atlas/report/watchlist/stories → tests → CI |

## Deploy (GitHub → Vercel)

1. Push this repo to GitHub.
2. Vercel → *Add New Project* → import the repo → framework auto-detects Next.js → Deploy.
3. Done. The build runs `npm run build`; artifacts are committed so no pipeline step is needed at deploy time.
   Optional: add `NEXT_PUBLIC_SITE_URL` env var. No other configuration required.

`npm run build` regenerates artifacts first if missing (`scripts/serve-artifacts.mjs` check + CI),
so deploys are reproducible from the registry alone.

## The science, in ten lines

- Interferogram stacks → **SBAS time-series inversion** → displacement per epoch.
- **Theil–Sen robust velocity** (Sen 1968 CI via Kendall's S) — insensitive to atmospheric outliers.
- **Joint harmonic fit** (annual + semi-annual) removes seasonal concavity before the slope —
  the MintPy-style approach; implemented in `lib/stats.ts` with tests.
- **Conformal calibration** (split / Jackknife+, Barber et al. 2021) on GNSS station velocities:
  finite-sample ⌈(n+1)(1−α)⌉/n quantile → **coverage guarantee**, verified per-AOI and printed on every report.
- **Signature classifier v1**: interpretable feature-rule scores over 4 physical signatures
  (subsidence bowl / landslide creep / structural motion / atmospheric artifact); CNN upgrade path documented.
- **Receipts**: JSON-LD per report — datasets+versions, parameters, software, validation stats, QC flags,
  SHA-256 content hash (tamper-check runs on the receipt page and in `/api/health`).

## Honest scope disclosure (read this, judges)

**This deployment runs on synthetic, literature-calibrated displacement series** — deterministic, seeded,
with per-epoch uncertainty — so the *full product shape* is auditable without a SAR processing cluster.
The receipts disclose this; the `/method` page flags it; nothing here pretends to be real NISAR pixels.

What is **real**: every statistical method (the exact code that would process real epochs), the uncertainty
calibration machinery, the receipt spec + hash verification, the agent's tool plan and schema guardrails,
the full product surface, the tests, the CI. Swapping in real NISAR/Sentinel epochs touches only
`data/registry.ts` + `scripts/run-pipeline.ts` — no downstream code changes.

## Architecture

```
[data registry]  data/registry.ts — AOI specs, GNSS truth, literature anchors
      │
[offline pipeline]  scripts/run-pipeline.ts (npm run pipeline)
  ingest → joint fit → velocity/seasonal decomposition → GNSS validation
   → conformal calibration → receipts (SHA-256) → JSON artifacts (data/artifacts)
      │
[data layer]  lib/data.ts — zod-validated server reads, cached
      │
[API]  /api/catalog /api/reports/[id] /api/timeseries/[id] /api/gnss/[id]
       /api/watchlist /api/receipts/[id] /api/reports/[id]/export (CSV/JSON)
       /api/alerts/subscribe (stub) /api/agent/plan /api/health
      │
[frontend]  Next.js 14 App Router + MapLibre GL + Tailwind
  / (atlas + epoch playback) /aoi/[id] (report) /watchlist /stories /method
  /receipts/[id] (public receipt viewer with hash verification) /about
      │
[agent]  lib/agent.ts — deterministic provenance-first planner
  CMR search → pick → download → coregister → invert → validate → receipt
  (optional LLM annotation path; degrades to manual with zero loss)
```

## Testing

```bash
npm test
```

- `tests/stats.test.ts` — Theil–Sen exactness + outlier robustness; joint-fit recovers velocity inside CI
  on seasonal arcs; conformal coverage on 500 synthetic calibration points; finite-sample widening.
- `tests/pipeline.test.ts` — schema-valid reports for all AOIs; **truth inside 95% CI**; coverage target met;
  determinism (byte-identical reruns).
- `tests/narrator.test.ts` — **numeric fidelity**: the narrator may only print numbers derivable from the
  report JSON (recursive walk of every field; zero violations tolerated).
- `tests/receipts.test.ts` — schema + **tamper detection** (mutated field → hash mismatch throws).
- `tests/classifier.test.ts` — signature classification sanity + valid distributions.
- `tests/agent.test.ts` — ordered tool plan ending in receipt; deadline-aware note.

## AI disclosure

Code was written with AI pair-programming (Codebuff agent + human review). All statistical methods are
standard published algorithms, implemented transparently in `lib/stats.ts` with tests. The demo agent is a
deterministic rule-based planner; the optional LLM path only annotates plan steps and can be disabled with
zero loss of function. The narrator is schema-constrained and tested for numeric fidelity. No AI-generated
science claims — every figure is computed by the pipeline and receipted.
